## 원본과 표시용 처리의 구분

크림·민트 타일 3개는 모두 **1254×1254 RGB**다. 알파 채널이 없고 불투명하며, 모서리에 포함된 어두운 픽셀도 원본 그대로다. 투명 PNG라고 부르지 않는다.

수호자 원본은 **1230×1278 RGBA**, 실제 알파 극값은 **0–255**다.

- 원본의 엄격한 비영 알파 경계: `[0, 47, 1166, 1278]`
- 표시용으로 선택한 알파 ≥ 8 경계: `[112, 323, 1163, 1166]`, 1051×843
- 경계 좌표는 왼쪽·위 포함, 오른쪽·아래 제외다.
- 극히 희미한 알파=1 점들이 엄격한 경계를 늘린다. 이 문제를 숨기지 않고 manifest에 개수와 두 경계를 함께 기록했다.
- 표시용 복사본에만 위 경계로 크롭했다. 크롭 내부의 원래 RGBA 값을 바꾸거나 알파를 임계값으로 잘라내지 않았다. 이후 LANCZOS로 축소했다. 원본은 크롭·덮어쓰기하지 않았다.
- 표시용 최대 변은 칸의 80% 이하: 144칸에서 115px, 60칸에서 48px. 비율은 Pillow thumbnail로 유지하며 정수 픽셀 반올림 차이는 있다.

### 측정한 발 피벗

알파 ≥ 128인 마지막 발 픽셀 행은 원본의 y=1164다. 이 행에서 발 두 개의 접지 구간은 x=401–442, 799–847이다. 픽셀 중심 좌표 기준 두 구간 중심의 중간값은 **(622.75, 1164.5)**, 원본 정규화값은 약 **(0.506301, 0.911189)**다. 캔버스 중심이나 관행적 (0.5, 0.9)를 원본 발 위치로 가정하지 않았다.

각 칸에서 이 측정 발 피벗을 칸의 (0.5, 0.9)에 맞춰 조립했다. 정수 위치 반올림으로 실제 접지점은 목표점과 최대 0.5px 다르다. 이미지의 기하학적 접지점을 측정한 것이며 물리·충돌·애니메이션 피벗을 검증한 것은 아니다. 모든 수호자 사각 영역이 자기 칸 안에 들어가는지 스크립트에서 검사한다.

## 실제 픽셀 확인 · 2026-10-10 UTC

작성자 시각 검사에서 원본 4개, 864판, 360판, 48×39 수호자 PNG를 직접 열었다. 다음은 독립 승인이나 사람 플레이테스트 결과가 아니다.

- 작은 판에서도 민트 외곽과 크림 중앙 4×4의 구분은 보인다.
- 수호자는 작은 크기에서 둥근 실루엣, 두 눈, 왼쪽 무기, 두 발이 남는다. 얇은 금속 테두리와 세부 반사는 축소되어 뭉친다.
- 같은 크기와 피벗으로 놓인 네 복사본은 칸 안에 들어가며 발이 타일 경계를 침범하지 않는다. 별도의 바닥 그림자는 합성하지 않아 접지감은 원본 명암에 의존한다.
- 크림 타일의 반복 테두리는 격자를 명료하게 하지만 경계가 이중으로 두꺼워진다.
- **민트 직선과 모서리의 색·붓결·금색 턱 폭 및 연결부가 일치하지 않는다.** 외곽 경로의 색 영역은 이어지지만 이음새가 보인다. seamless 통과로 표시하지 않는다.
- **모서리·측면에 원본을 회전해서 구운 하이라이트와 그림자도 회전한다.** 장면 전체의 좌상단 광원을 통일한 것으로 주장하지 않는다.
- 수호자 알파=1 잡점은 원본 정리 위험으로 남는다. 표시 크롭으로 투명 여백 문제를 줄였을 뿐 원본 알파를 수정·정리한 것은 아니다.
- 원본에는 UI 글자·숫자·별·체력 레이어를 추가하지 않았다. 아트 방향·가독성의 최종 통과 여부는 다른 두 후보와 같은 기준으로 검토해야 한다.

manifest의 이음새 수치는 가로·세로 인접 타일 60쌍의 RGB 경계 평균 절대 차이다. 통과 임계값이 없는 관찰값이며 연결성·광원·미적 품질 판정을 대신하지 않는다.

브라우저 게임 조작, 자동 전투 시뮬레이션, 사람 플레이, 독립 동료 리뷰, production 편입은 이 조립 검사에서 수행하지 않았다.

## 출처와 참고 이미지

## 재현과 검증

저장소 루트에서 Python과 Pillow를 사용할 수 있을 때 실행한다. 현재 검증 버전은 Pillow 12.3.0이다.

```sh
python assets/candidates/round-01/kiki/assemble.py
```

스크립트는 자기 하위의 `display/`, `comparison/`, `manifest.json`만 재생성한다. `originals/`와 다른 담당 범위를 변경하지 않는다. 새 아트 픽셀을 그리거나 그라디언트·도형으로 대체하지 않으며, 원본 읽기·표시용 크롭·축소·정수 90도 회전·알파 합성만 수행한다. 스크립트의 빈 조립 캔버스는 36개 타일로 완전히 덮인다.

패키징 검증은 PNG 14개 전체 디코드, 원본 4개의 생성 파일 대비 바이트 해시 일치, 36칸 배치와 20칸 외곽 순서, 4기물의 칸 내 배치, manifest의 14개 파일 크기·모드·알파·SHA 일치, 스크립트 2회 실행의 동일 결과를 확인했다. Pillow 버전에 따라 축소·인코딩 결과 해시가 달라질 수 있으므로 재생성 결과를 다시 확인해야 한다.

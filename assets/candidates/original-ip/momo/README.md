# 절기권사 — 모모 독립 IP 제안

Issue #19 · generation 1 · 디펜스 전용 신규 IP 후보. 가챠샵 원본 미반영.

- `cast-concept-v1.png`: 8인 외형/의상/도구 설정용 원본 생성 시안.
- `cast-sd-v1.png`: 동일 8인의 SD 게임 기물 비율 탐색 시안.
- 대응 JPG: 사용자 열람용 흰 배경 RGB 변환. 원본 PNG는 보존.
- 번호: 위 01나도/02든/03소리/04보준, 아래 05련/06하온/07무레/08설기.
- 설정집: `docs/design/original-ip/momo.md`.

두 PNG는 built-in image_gen으로 실제 생성하고 모모가 각각 픽셀을 직접 확인했다. 두 번째는 첫 이미지를 정체성 참고로 사용했다. 원본 가챠샵/기존 캐릭터 시트는 입력하지 않았다. 프롬프트는 prompts.json에 기록한다.

검수: 두 장 모두 8인/번호/전신/핵심 색·도구 차별화 확인. 설정용은 긴 비율이고 SD용은 큰 머리/짧은 몸으로 별도 변환했다. 나도 주먹/소리 부채/보준 각진 권갑/무레 둥근 숄의 실루엣이 다르다. 투명 배경 스프라이트·아틀라스·모션·실제 모바일 44px 가독성 검증은 아직 아니다. SD의 작은 장식과 손 표현은 게임용 제작 때 추가 단순화/정합 검수가 필요하다. 셀 구분선과 그림자는 컨셉시트 배경이며 게임 에셋으로 직접 사용하지 않는다.

기존 특정 작품을 지명하거나 외형을 복제하는 프롬프트는 사용하지 않았다. 이는 법적 독창성 보증이나 유사 이미지 전수 검색 완료를 뜻하지 않는다. 등급/역할/시너지 수치는 제안이며 생산 에셋 채택·게임 균형 검증과 구분한다. 같은 크기의 3성 변형 연출도 공간 점유 규칙 결정을 대신하지 않는다.

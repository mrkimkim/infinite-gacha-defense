# 무한의 가챠 디펜스

기존 infinite-gacha와 분리된 신규 게임 프로젝트입니다. 가희의 가챠 상점 모티프와 정면 4×4 정사각형 콘셉트를 출발점으로 삼습니다.

저장소: https://github.com/mrkimkim/infinite-gacha-defense (공개)

현재는 독립된 세 닷(리더·모모·키키)의 협업 프로토콜 검토 단계입니다. 게임 구현과 수치는 확정되지 않았습니다. 소유자는 2026-10-10 프로젝트 공개 게시, 팀 소통, Issue·브랜치·PR 운영 및 MVP까지 리뷰·테스트를 통과한 변경의 리더 병합을 명시적으로 승인했습니다. 배포·권한 확대·무관한 공개는 이 범위에 포함하지 않습니다. 초기화 예외: 이 최초 프로토콜·문서·템플릿 게시만은 소유자의 명시적 승인에 따라 실제 동료 온보딩 전 리더가 게시할 수 있습니다. 이는 문서 초기화에 한정되며 동료 리뷰를 받은 것으로 표시하지 않습니다. 게임 구현·후속 변경은 해당 시작 게이트와 리뷰·테스트 규칙을 따릅니다.

[작업 지침](AGENTS.md), [협업 프로토콜](docs/team/PROTOCOL.md), [MVP 제안](docs/team/MVP_PLAN.md), [현재 상태](docs/team/STATUS.md)를 먼저 읽으세요.

공개 저장소에는 이 프로젝트의 문서·코드·공개가 승인된 원본 아트·기술 논의만 게시합니다. 사적인 대화, 토큰, 관련 없는 미공개 IP, 재배포 권리가 없는 에셋은 게시하지 않습니다. 기존 세계관과 참고 자료는 허용된 접근 범위에서 읽을 수 있지만, 비공개 원문·이미지·에셋을 별도 허락 없이 복사해 공개하지 않습니다.

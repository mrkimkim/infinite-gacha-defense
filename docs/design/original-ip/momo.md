## 1. 한 문장과 세계

**계절이 뒤엉킨 세상에서, 날씨를 매듭에 접어 지닌 여덟 권사가 몸짓으로 봉인을 펼쳐 마을을 지킨다.**

봄비가 한여름 땅을 얼리고, 겨울 한복판의 돌풍이 마을 지붕을 뜯어 가는 시대다. 사람들은 계절 폭풍 사이의 짧은 고요에 정착지를 이어 간다. 권사들은 바람띠에 날씨의 결을 접고 작은 도자기 절기패에 봉인하는 기술을 익혔다. 자세를 낮추고, 매듭을 풀고, 한 번의 정확한 동작으로 축적한 날씨를 돌려보낸다. 여덟 사람은 하나의 계절을 영원히 승리시키려 하지 않는다. 서로 다른 날씨가 지나갈 차례를 되찾아 사람들이 다시 씨를 뿌리고 길을 건너게 하는 것이 목표다.

장르는 **무술·기상 변신 판타지**다. 생활 도구를 손질하는 손맛, 발을 딛는 자세, 접힌 것이 펼쳐지는 변화가 정체성이다. 설정상 방어 대상은 정착지이며 적의 구체적 종족·외형과 새 전투 규칙은 이 제안으로 확정하지 않는다.

## 2. 시각 DNA

- **공통 형태:** 읽히는 손발과 자세, 짧고 긴 상의의 대비, 옷 밖으로 드러나는 매듭 하나와 대표 도구 하나. 정면에 가까운 살짝 위 시점의 손그림 2.5D 후보를 지향한다.
- **재료:** 무광 면·마 직물, 납작하게 접힌 날씨 리본, 손으로 빚은 도자기, 소량의 구리 장식. 도자기는 매끈한 게임 아이콘으로 단순화하되 각진 테두리와 유약 색면으로 구별한다.
- **팔레트:** 남색·청록·자주를 바탕으로 살구·황토·산호를 분배한다. 인물마다 주색 두 개와 포인트 한 개를 우선하며 날씨 효과가 얼굴과 도구를 가리지 않게 한다.
- **문양:** 원형 햇살, 삼각 돌풍, 세 갈래 빗줄기, 각진 돌결, 초승달 서리, 꺾인 번개, 둥근 구름, 접힌 육각 절기패. 색을 빼도 서로 다른 윤곽으로 읽혀야 한다.
- **변화의 문법:** 매듭이 풀림 → 띠/패가 펼쳐짐 → 해당 날씨의 궤적이 자세를 완성함. 머리색 일괄 변경이나 의상 전체 교체 없이도 같은 인물임을 유지한다.
- **독자성 기준:** 특정 유명 캐릭터의 이름·머리·도복·로고·기탄·변신색을 재현하지 않는다. 이 방향은 제작 기준이며 법적 독창성이나 권리 검토 완료의 보증이 아니다.

나도는 끊김 없는 기본 화력, 든은 흩어진 적, 소리는 밀집한 적, 보준은 느린 강타를 맡는 구상이다. 련은 진행 제어, 하온은 분절된 연타, 무레는 배치 지원, 설기는 조건부 전문화를 맡는다. 높은 등급이 앞선 인물의 역할을 그대로 상위 호환하지 않도록 비교한다. 예를 들어 보준의 근거리 강타와 설기의 긴 준비·거리 대응은 서로 다른 배치 선택이어야 한다. 이는 수치나 구현 완료의 진술이 아니다.

## 4. 변신과 성장의 시각 계획

기본형에서도 무술 자세와 도구가 보인다. 변신은 날씨를 담은 **봉인을 펼치는 연출**이며, 별 성장의 외형 후보와 연결할 수 있다. 새로운 수동 변신 버튼이나 자원 시스템을 이 문서로 추가하지 않는다.

| 표시 단계 후보 | 공통 변화 | 유지할 것 |
|---|---|---|
| 1성 기본형 | 단단히 묶인 띠, 접힌 도자기패, 공격 때만 짧은 날씨 궤적 | 얼굴, 머리, 주색, 대표 도구 |
| 2성 전개형 | 대표 매듭 한 곳이 풀리고 띠/패의 안쪽 문양이 드러남 | 몸 크기, 발 위치, 도구의 윤곽 |
| 3성 절기형 | 펼쳐진 문양이 자세를 둘러 하나의 완성된 기상 도형을 만듦. 평상시 효과는 낮추고 공격 순간에 강조 | 같은 인물의 실루엣과 보드 가독성 |

인물별 핵심 변화: 나도는 미트 바깥의 해 고리, 든은 발목 리본의 바람 날개, 소리는 세 부채판 사이의 빗줄기, 보준은 보호구의 돌결 이음선, 련은 목도리의 서리 초승달, 하온은 두 손목을 잇는 번개 박자, 무레는 지팡이 고리의 구름 물결, 설기는 세 육각패가 펼쳐 만드는 절기 바퀴다.

**현재 사용자 규칙과의 경계:** 고유 희귀도는 일반/고급/희귀/영웅/전설 5단계이며 1–3성과 별개다. 같은 캐릭터·같은 별 3개가 자동 승급하고 Lv·XP·책은 사용하지 않는다. 공간 외 별도 머릿수 제한을 추가하지 않는다. **3성의 2×2 점유는 미결정**이므로 그림을 크게 만드는 것으로 이를 확정하지 않는다. 변신 연출의 범위가 유닛 점유 영역이나 공격 판정을 바꾸지 않는다.

## 5. 시너지 초안

아래는 기획 비교용 태그다. 저장 스키마, 발동 임계치, 지속시간, 중첩 방식과 수치는 아직 확정하지 않는다. 기존 IP의 공식 설정이나 모든 신규 IP에 강제되는 규칙으로 취급하지 않는다.

### IP 내부: 절기권사 / 절기 순환

여덟 사람이 속하는 소속 태그 **절기권사**를 제안한다. 단순히 같은 IP 여덟 명을 채우면 모든 능력이 크게 증가하는 구조보다, 서로 다른 권사를 배치했을 때 방어 리듬을 보완하는 작은 보상을 비교한다. 중복 복제는 고유 인물 수를 늘리지 않는 안을 우선 검토한다. 순환 문양 연출과 실제 전투 보상은 분리하며, 효과를 채택하기 전에는 장식만으로 버프가 있다고 표시하지 않는다.

### IP를 넘는 플레이 태그

| 후보 태그 | 이 IP의 후보 인물 | 다른 IP와 연결할 역할 | 검토할 대가/위험 |
|---|---|---|---|
| **연격** | 나도·하온 | 빠른 단일 또는 분절 타격 | 공격속도 지원과 중복 증폭해 유일한 정답이 되지 않도록 검토 |
| **파동** | 든·소리 | 여러 대상 또는 범위 처리 | 흩어진 적과 밀집 적의 차이를 지우지 않는 보상이어야 함 |
| **집중** | 보준·설기 | 긴 준비 뒤 단일·보스 대응 | 전설 보상으로 낮은 등급의 보스 대응 자리를 없애지 않음 |
| **조율** | 련·무레 | 진행 제어 또는 이웃 지원 | 제어·지원 중첩, 무한 지연, 복제 오라 누적 위험 검토 |

교차 태그는 한 IP를 완성하지 않아도 다른 IP의 같은 역할과 연결하는 장치다. 첫 화면에 네 종류를 모두 필수 학습으로 밀어 넣기보다, 채택 실험에서 핵심 태그를 추리는 것이 좋다. 효과를 추가하지 않은 상태에서도 여덟 인물의 기본 공격은 구별되어야 한다.

## 6. 작은 기물에서 확인할 것

- 같은 길이의 가운과 같은 얼굴 여덟 개가 되지 않게 **단발+짧은 재킷 / 삼각 판초 / 고리 땋은 머리+부채 / 각진 양팔 / 비대칭 코트+초승달 / 드러난 팔+쌍손목 / 둥근 숄+고리 지팡이 / 갈라진 코트+육각패**를 먼저 읽는다.
- 실제 게임 표시 크기로 축소하여 번호 없이 구별하는 검사를 한다. 도구와 자세가 얼굴 디테일보다 먼저 읽혀야 한다. 컨셉 시트의 크고 깨끗한 이미지만으로 통과 처리하지 않는다.
- 공격은 준비 → 타격 → 복귀의 박자가 있어야 한다. 이펙트 색만 바꾼 동일 발사 모션 여덟 개로 대체하지 않는다.
- 날씨 리본과 코트 끝이 이웃 기물, 별 표시, 적의 체력바를 가리지 않게 한다. 겹침은 보드 위에서 확인한다.
- 고유 희귀도와 별 수는 서로 다른 UI 정보로 읽혀야 한다. 전설의 밝은 옷이나 3성 효과가 선택·피격·사거리 표시보다 강해지지 않게 한다.

## 7. 아트 연결과 현재 한계

실제 생성된 두 PNG를 열어 8인과 번호 순서, 주요 색·도구를 확인했다. 첫 시트는 약 4등신의 전신 설정 비교용이고 두 번째는 큰 머리·짧은 팔다리의 SD 비교용이다. 둘 다 기본형 후보이며 변신 전후 시트가 아니다.

| 파일 | 목적 |
|---|---|
| [cast-concept-v1.png](../../../assets/candidates/original-ip/momo/cast-concept-v1.png) / [열람 JPG](../../../assets/candidates/original-ip/momo/cast-concept-v1.jpg) | 전신 컨셉. 의상·재료·무술 자세 비교 |
| [cast-sd-v1.png](../../../assets/candidates/original-ip/momo/cast-sd-v1.png) / [열람 JPG](../../../assets/candidates/original-ip/momo/cast-sd-v1.jpg) | 같은 8인의 SD 비례 후보. 작은 기물화 방향 비교 |

- 두 시트 모두 1536×1024이며 배경을 포함한 RGB 이미지다. 알파가 있는 분리 에셋으로 취급하지 않는다. 번호는 인물 매핑 보조이며 이름표 UI가 아니다.
- **목표와 실제의 차이:** 01의 머리는 곧은 단발보다 잔머리·묶음이 있는 단발로, 02는 뒤로 넘겨 묶은 긴 남색 머리로 그려졌다. 04의 흰 땋은 머리는 목표보다 길며 첫 시트에서 더 두드러진다. 03의 부채 세 판은 유지되지만 복장은 치마형 외피가 더해져 통바지 윤곽이 약해졌다.
- 08에는 꽃·눈·잎의 육각패 세 개와 원형 햇살/손바닥 효과가 보인다. 첫 시트는 네 계절 아이콘으로 읽히며 SD는 세 육각패와 빛나는 원형 효과가 구분된다. **접힌 패가 펼쳐지는 단계와 어깨 주변 배치는 아직 구현되지 않았다.** 이 원형 효과를 네 번째 도자기패로 세지 않는다.
- 이 차이는 숨기지 않고 차기 외형 정리 항목으로 남긴다. 기본 미트·바람 리본·세 판 부채·각진 보호구·서리 목도리·쌍손목·고리 지팡이·기상패의 대응은 확인했으나 모든 의상 세부와 성격 표현이 최종 기준에 일치한다고 판정하지 않는다.
- 컨셉 시트는 **제작용 스프라이트가 아니다.** 분리 프레임, 투명 배경, 피벗, 보드 점유 경계, 공격 방향, idle/공격 모션과 실제 플레이 가독성은 후속 제작·검증 대상이다.
- 수치 밸런스, 밀치기 엔진, 새 태그 시스템, 최종 합성 연출을 이 문서에서 구현하거나 승인하지 않는다. 원본 가챠샵·다른 제안자의 파일·production 에셋은 이 제안의 수정 범위가 아니다.
- 최종 채택은 두 동료의 독립 검토와 팀의 결정 기록을 거친다. 내부 작업 분담이나 생성 도구의 출력 자체를 독립 동료 리뷰로 세지 않는다.

# 리더 신규 IP 제안 — 미드나잇 금고단

**디펜스 전용 오리지널 / 가칭 / 컨셉아트 기준 v2 / 공동 검토 전 초안.** 가챠샵에 추가하지 않으며 원본 infinite-gacha 저장소를 수정하지 않는다. 모모·키키의 별도 신규 IP는 각자의 독립 제안이다. 이 문서는 리더의 설정집이며 세 닷 합의로 표시하지 않는다.

## 세계관과 이야기

도시의 등불이 하나씩 꺼지는 밤, 마을의 빛과 기억이 옛 마법 금고 안에 봉인된다. 미드나잇 금고단은 금화를 모으는 강도들이 아니라 주인에게 돌아갈 기억과 일상을 찾아 주는 여덟 사람이다. 금고의 문은 하나의 열쇠로 열리지 않는다. 장치의 틈을 찾고, 경비 환영을 따돌리고, 잠금 장치를 해체하는 서로 다른 기술이 필요하다.

첫 이야기의 목표는 새벽 종이 울리기 전 ‘돌아오는 길의 기억’을 되찾는 것. 옛 장치를 만들었던 베른과 기록을 남겼던 오르는 사건의 책임을 피하지 않는다. 젊은 단원들이 단순한 후계자가 되기보다 각자의 방식으로 새로운 해법을 찾는 것이 관계의 중심이다. 악역/도시명/세부 연대기는 미정이다. 유명 괴도 작품의 캐릭터·로고·상징을 옮기지 않는다.

## 8인 — 이미지와 같은 순서

모두 성인 인간이다. 윗줄01~04, 아랫줄05~08 순서로 컨셉아트를 대조한다. 공통 짙은 남색/구리/크림을 바탕으로 지정된 개인 강조색과 도구를 유지한다. 등급은 성격/연령/신체 크기의 서열이 아니다.

### 01 니아 · 일반 후보

- **외형 고정 초안:** 작은 체구 여성, 짧은 구리색 곱슬머리, 청록 작업조끼, 큰 고리형 열쇠도구.
- **성격:** 늘 질문부터 하는 신중한 수리공. 다급하면 열쇠를 손가락으로 돌린다.
- **관계:** 베른에게 도구를 배웠지만 힘보다 해법을 먼저 찾는다.
- **역할/속성 제안:** 지원 / 빛. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 고리 열쇠가 표적 하나의 잠금 표식을 잠시 느슨하게 해 받는 피해를 소폭 증가; 동종 최강 하나·짧은 지속·영구 누적 없음. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 열쇠를 들어 회전→표식 점등→접기.

### 02 토마 · 일반 후보

- **외형 고정 초안:** 통통한 남성, 짧은 밤색 머리, 겨자색 누빔 앞치마, 접이식 미끼 꼭두각시.
- **성격:** 농담으로 긴장을 풀되 모두의 퇴로를 먼저 확인하는 무대 장치공.
- **관계:** 베라와 임기응변 호흡이 좋고 마레의 신호 없이는 미끼를 터뜨리지 않는다.
- **역할/속성 제안:** 다중 / 그림자. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 접이식 미끼가 짧게 나타나 직선상 최대 두 적을 관통 사격; 미끼는 연출이며 추가 기물/소환/시너지 인원 아님. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 인형 펼침→짧은 관통 발사→인형 접힘.

### 03 베른 · 고급 후보

- **외형 고정 초안:** 큰 체구 남성, 짙은 피부, 짧은 회색 머리, 남색 작업복과 구리색 어깨보호대, 커다란 금고손잡이형 망치.
- **성격:** 금고를 만들었던 장인. 말수가 적고 실수한 동료를 먼저 감싼다.
- **관계:** 니아의 스승이며 과거 만든 잠금 장치를 오르와 함께 해체하려 한다.
- **역할/속성 제안:** 범위 / 대지. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 망치를 내려 주 타깃 중심의 작은 범위에 파쇄 피해; 길/보드/적 경로를 파괴하지 않음. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 망치 당김→내려침→작은 먼지 고리→회수.

### 04 마레 · 고급 후보

- **외형 고정 초안:** 장신 여성, 자주색 땋은머리, 넓은 청록 판초, 향수병형 연막기.
- **성격:** 향의 지속시간을 초 단위로 외우는 차분한 퇴로 설계자.
- **관계:** 토마의 장치를 점검하며 성급한 루크에게 철수 신호를 맡긴다.
- **역할/속성 제안:** 둔화 / 물. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 표적 주변의 얇은 연막으로 이동 둔화; 동종 최강만·보스 적용률 별도 공개·경로 시야 가림 없음. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 병 들어 누름→낮은 연무→손 원위치.

### 05 시온 · 희귀 후보

- **외형 고정 초안:** 날씬한 남성, 흰색 짧은머리, 자두색 짧은 코트, 접힌 기계식 와이어보우.
- **성격:** 거리를 재고 나서 말하는 과묵한 측량사. 완벽한 계획이 깨질 때 약하다.
- **관계:** 베라와 즉흥성 때문에 티격태격하나 서로 사각을 맡아 준다.
- **역할/속성 제안:** 다중 / 바람. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 장거리 직선에 와이어 볼트를 발사해 최대 두 적 관통; 대상/교차 판정과 두 번째 피해 감소는 검토 필요. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 보우 펼침→당김→직선 발사→접힘.

### 06 베라 · 희귀 후보

- **외형 고정 초안:** 보통체격 여성, 검은 단발, 크림색 비대칭 재킷과 빨강 소매, 구리 카드부채.
- **성격:** 즉흥 연기에 강하지만 동료의 약속에는 엄격한 안내인.
- **관계:** 시온에게 계획 바깥의 탈출구를 보여 주며 토마의 인형 대사를 만든다.
- **역할/속성 제안:** 다중 / 열. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 부채에서 서로 다른 최대 두 적에게 카드 한 장씩; 적 하나면 한 장·같은 적 중복 명중 없음. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 부채 펼침→두 갈래 투척→빈손 복귀.

### 07 루크 · 영웅 후보

- **외형 고정 초안:** 긴 팔다리 남성, 짙은 남색 언더컷, 긴 청록 스카프와 남색 짧은 재킷, 두 개의 굽은 갈고리.

- **자동능력 제안:** 보스 우선 갈고리 약점 타격; 일반 적 효율은 낮게·끌기/기절/무한 약점 중첩 없음. 발동주기·계수·범위·상한은 미확정이다.

- **외형 고정 초안:** 작고 당당한 노년 여성, 풍성한 은회색 올림머리, 자두색 종 모양 망토, 떠 있는 깨진 금고다이얼.

- **관계:** 베른과 과거 장치의 책임을 나누며 니아를 후계자로 정하지 않고 스스로 길을 찾게 한다.
- **역할/속성 제안:** 범위 / 그림자. 원작에서 물려받은 능력이 아닌 신규 설계다.
- **자동능력 제안:** 깨진 다이얼이 표식을 남기고 다음 공격에 연쇄 폭발; 연쇄 대상 수/횟수 상한 필요·폭발이 새 표식/재귀 폭발을 만들지 않음. 발동주기·계수·범위·상한은 미확정이다.
- **공격 모션:** 다이얼 펼침→표식→제한 연쇄 점등→조각 정렬.

## 자동전투와 시너지

수동 조작 필살기 없이 준비 편성과 자동 공격으로 역할이 보이게 한다. 카드의 두 갈래, 직선 와이어, 망치 범위, 연막 둔화, 표식 점등을 서로 다른 모양으로 구별한다. 지원도 시각적인 원인과 대상을 보여 준다. 공격을 결정하는 것은 코어의 확정 이벤트이며 모션 프레임/렌더링 지연이 피해 판정을 바꾸지 않는다.

IP ‘금고단’ 고유2/4명에서 소속 기본피해가 조금 증가하는 공통 로스터안으로 먼저 비교한다. ‘봉인 해제 후 다음타 강화’ 같은 테마형 대안은 추가 이벤트/연쇄 복잡도가 크므로 별도 후보로 남긴다. 중복 캐릭터·성급·벤치·2×2 점유는 인원 증가로 세지 않는다.

교차 직업은 시온/토마/베라가 다중, 베른/오르가 범위, 마레가 둔화, 루크가 보스, 니아가 지원이다. 같은 다중 태그라도 직선 관통과 독립 두 발은 구별한다. 시온의 다중·바람, 루크의 보스·대지 태그로 같은 태그의 타 IP 후보와 연결할 수 있다. 직업2/4 사거리 증가와 속성3/5 피해 증가 후보는 전체 로스터 검토안과 맞추며, 속성은 첫 실험 비활성 비교군이다.

니아는 표적의 받는 피해를 잠시 늘리는 디버프 후보다. 기존 인접 공격주기 오라를 조용히 대체하지 않는다. 동종 약화는 최강 하나만, 중첩 상한·지속·보스 처리·저항 공개가 필요하다. 오르는 표식 폭발이 다시 폭발을 유발하지 않는 유한 구조여야 한다. 토마의 미끼는 추가 기물/돈/시너지 인원을 만들지 않는다. 코인 강탈·아이템 복제·영구 파밍 효과를 기본으로 확정하지 않는다.

## 2.5D 그림체 규칙

2.5등신 손그림 기반의 부드러운 입체 명암. 정면에 가까운 살짝 위 시점을 유지하고 발바닥 기준선을 맞춘다. 외곽은 굵고 단순하며 작은 재질 디테일보다 얼굴·도구·의상 덩어리를 우선한다. 공통색은 짙은 남색/구리/크림, 개인색은 지정된 청록/겨자/자두/빨강 계열 강조를 따른다. 사람마다 체형 차이는 남기되 오르를 전설이라는 이유로 확대하지 않는다.

모든 얼굴을 읽을 수 있어야 한다. 전원 동일 가면/모자/정장 금지. 단일한 케이프 실루엣으로 통일하지 않는다. 베른의 넓은 망치형, 마레의 판초형, 루크의 긴 스카프/갈고리형, 오르의 작은 종형 등 최소 실루엣 차이를 44~56px 축소에서 검토한다. 떠 있는 다이얼은 오르를 가리거나 이웃 칸을 지나치게 침범하지 않는다. 번호/이름은 캐릭터 몸 안에 그리지 않고 외부 라벨로 관리한다.

## 모션 제작 요건

첫 컨셉아트는 정체성과 스타일 비교용이며 게임용 스프라이트 완료가 아니다. 캐릭터별 투명 배경으로 idle/공격 준비/발사 또는 타격/복귀/승리 반응의 컷을 따로 제작한다. idle은 최소2개 키 포즈, 공격은 준비→접촉/발사→회수 최소3개 키 포즈에서 원인이 보이게 한다. 프레임 수·재생속도·시트 크기는 엔진/웹 계약과 실제 축소시험 후 정한다.

모든 컷에서 동일 캔버스·발 기준점·카메라·머리 크기·도구 손을 유지하고 metadata에 프레임 순서/anchor/도구 발사점/시각 contact 프레임을 기록한다. 이미지에는 이름/그리드/배경이 없는 게임용 컷과 라벨 있는 검토용 시트를 분리한다. 그림자 처리 방식은 웹 합성과 함께 결정한다. 도구/손/팔다리 수 변화, 좌우 반전, 와이어 잘림, 이웃 셀 가림, 배경 잔여 픽셀을 실물로 검사한다.

44/56px와 실제 보드에서 idle·발사·대상 피격이 구별되는지 브라우저로 확인한다. 아트가 아직 생성되지 않았거나 접근되지 않은 경우 텍스트로 확인했다고 대신 기록하지 않는다. 실제 이미지 링크/버전·생성 후 검수·동료 두 명 의견은 후속 기록 대상이다.

## 검토 상태

이름/외형/순서는 리더의 컨셉아트 제작 기준 v2와 맞췄다. 앞서 게시한 세린 등 v1 8인은 폐기되었으며 후보80명에 섞지 않는다. 설정집의 세계관·관계·능력은 이 외형을 바탕으로 새로 제안했다. 리더의 별도 제작 세션에서 설정용 긴 비율과 전장용 SD 비율 컨셉아트 2장을 생성·실물 검수·사용자 전달했다고 보고했다. 이 문서 작성 환경에서는 두 이미지 픽셀을 직접 확인하지 않았다. 전장용은 큰 머리/짧은 팔다리로 수정했지만 잔장식이 남아 있으며 48px 세부 가독성 검증 전이다. 이미지에는 최종 성능/등급 텍스트를 넣지 않았다. 이 PR에는 이미지가 포함되지 않는다. 애니메이션/production 에셋/두 동료 독립 리뷰/최종 채택/게임 플레이 검증은 미완료다. 모모·키키 파일·에셋은 작성하지 않았다.

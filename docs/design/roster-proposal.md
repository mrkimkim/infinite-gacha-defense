# 로스터 후보 — 10 IP × 8명

상태: **리더 제안 / 독립 리뷰 대기 / 구현 입력 아님**. 기존 정체성 60명과 디펜스 신규 제안 20명으로 총 80명이다. 기존 IP 부족분 12명과 신규 괴도단 8명을 구분한다. 모든 능력·등급 배치·속성·첫 출시 범위는 제안이다. 사용자가 승인한 것은 IP별 서로 다른 8명 구성, 5등급 명칭, 부적합 유사 IP 제외 방향과 디펜스 전용 괴도단 추가 방향이다. 80인 전부의 채택이나 아트 완성을 뜻하지 않는다.

## 출처와 범위

기존 60명의 이름·별칭·종/정체성은 허용된 원본 설정 텍스트와 대조했다. 원본 저장소를 수정하지 않았다. 텍스트 확인은 모든 캐릭터의 실제 픽셀·외형 적합성·재배포 검증을 대신하지 않는다. 상세 JSON은 별도 준비 중이다. 신규 괴도단 설정은 PR #32의 리더 설정집을 참고한다. 이 문서는 런타임 스키마가 아니다.

- 복닥복닥 우리동네는 잠정 제외한다. 사용자가 지목한 이미지와 직접 일치 확인 전이며 참고 작품명만으로 표절이라고 판정하지 않는다.
- 가희의 8개 의상은 8인으로 세지 않는다. 가희는 상점 모티프다.
- 메가기어의 메카/파일럿은 한 기물이다. 벌워크 카이는 자율 코어이며 별도 인간 파일럿을 만들지 않는다.
- 와일드링크는 몬스터 8종이다. 인간 파트너 나루/테오는 이 8종에 넣지 않는다.
- 셔틀 크라운의 전투 연출은 디펜스용 각색이다. 원작 배드민턴 선수가 실제 초능력을 가졌다고 소급하지 않는다.
- 희귀도와 ★성급은 별개다. IP마다 일반2/고급2/희귀2/영웅1/전설1 배치는 검토용으로, 서사상 우열이나 최종 획득 확률이 아니다.

## IP와 교차 시너지 제안

IP는 소속 태그, 직업은 단일/범위/다중/둔화/지원/보스 여섯 역할, 속성은 빛/물/대지/바람/열/그림자의 게임용 태그다. 속성은 원작 설정의 단정이 아니다. 예를 들어 와이어보우를 쓰는 시온과 바람형 카이트코, 루루가 IP를 넘어 다중/바람 편성을 만들고, 루크와 앵커 크랩은 보스/대지 역할을 공유한다.

첫 비교안은 IP 2/4명 피해 증가와 같은 직업 2/4명 사거리 증가다. 속성 3/5명 피해 증가안도 데이터로 검토하되 첫 실험에서는 비활성 비교군으로 둔다. 키키의 두 축 내외 안내 의견을 반영해 처음부터 세 축을 모두 활성화하지 않는다. 수치·상한·모든 IP의 같은 효과 적용 여부는 독립 리뷰와 플레이 실험 전 미정이다.

배치된 고유 캐릭터 종류(character definition ID)만 센다. 개체별 instance ID는 시너지 종류 수로 세지 않는다. 같은 캐릭터 중복, 성급, 벤치, 2×2 점유는 시너지 인원을 늘리지 않는다. 자동 합성 전후에도 같은 캐릭터 종류는 하나로 세며, 마지막 개체가 빠져 해당 종류가 사라지면 시너지를 다시 계산한다. 동종 지원은 가장 강한 하나만, 자신/벤치는 제외한다. IP·직업·속성의 중복 증폭과 지원만 채운 편성의 이득은 별도 검증한다. 니아의 잠금약화는 현재 인접 지원과 다른 표적 디버프 후보이므로 별도 리뷰 대상이다. 토마/시온의 직선 관통은 베라의 독립2발과 다르며 기존 엔진 계약에 포함됐다고 보지 않는다. 무한 소환·코인 강탈·영구 누적 약화는 기본 효과로 채택하지 않는다.

## 제작 규모와 경기별 뽑기 풀

첫 6 IP(꼬물상사~와일드링크) 48명은 리더의 제작 범위 제안이며 합의되지 않았다. 신규 괴도단은 먼저 컨셉아트와 설정을 검토한다. 제작 목록 80명, 첫 제작 후보 48명, 한 경기 추첨 풀은 서로 다른 결정이다.

키키는 플레이어가 2 IP를 골라 16명 풀로 경기하는 대안을 제안했다. 채택되지 않았으며 특정 조합이 보스/둔화/지원에 접근하지 못하는 문제, 고등급 희소성, IP 선택으로 얻는 고정 정답을 확인해야 한다. 속성/역할 보완은 IP 밖 지원 슬롯, 회전 모집, 선택 모집 등을 비교할 수 있으나 모두 추가 제안이다.

단순 독립·균등·복원 추첨에서 처음부터 특정 1종 9장을 보려면 기대 개별 노출 수는 9N이다. N=80이면720회,48이면432회,16이면144회다. 각각 3칸 상점으로 나눈240/144/48회는 **노출량 환산**일 뿐 정확한 유료 갱신 기대횟수가 아니다. 무료 초기상점·3칸 내 중복제한·구매 자금·유한 공동풀·등급별 확률은 이 계산에 없다. 특정 등급 총확률 r, 그 등급에 n종이 균등하면 p=r/n이고 기대 노출은9n/r이다. 확률을 정하지 않은 현재 이 값으로 3성 달성 가능성이나 재미를 입증할 수 없다.

필요 실험: 공개된 확률/비용/웨이브 예산으로 목표9장 달성률·최초3성 시점·실패분포, 일반 적/보스 대응 공백, 반복 IP 최적화, 합성 전후 벤치/칸 제약, 실제 사람이 이해한 시너지 수를 비교한다. XP책 없음·3장 자동합성·8기물 상한 제거 방향을 이전6명 fixture 규칙과 혼동하지 않는다. 3성2×2 점유 여부는 별도 미정이다.

## 독립 의견과 미결정

- [모모 역할 의견](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094378529), [키키 역할 의견](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094379710): 실제 전투 역할 차이, 중복 지원 억제, 고유 캐릭터 기반 시너지라는 원칙을 반영했다.
- [모모 6명 절충 동의](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094411771), [키키 6명 절충 동의](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094424317)는 당시 실험에 관한 동의다. 이 80인/등급/속성 배치의 승인이 아니다.
- [키키 최신 로스터 의견](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094751468)은 IP별8명/5등급 방향 수용, 48명 제작과16명 경기 풀 분리 제안, 실제 아트 검토 필요를 명시한다. 당시72명 언급 이후 괴도단8명 추가까지 동의한 것으로 확대하지 않는다.
- [신규 괴도단 방향](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094735287), [독립 IP 제안 요청](https://github.com/mrkimkim/infinite-gacha-defense/issues/19#issuecomment-6094748556), 8인 외형 기준 v2(리더 컨셉아트 정합 초안)을 따랐다. 모모/키키의 별도 신규 IP는 본 문서에서 대신 만들거나 자동 채택하지 않는다.

전체80인과 신규20명, 희귀도 배치,48명 출시 범위, 경기별 풀, 시너지 수치에 대한 두 동료 독립 리뷰는 대기 상태다. 실제 생성 컨셉아트·모션·게임 구현·플레이 검증 완료를 주장하지 않는다.

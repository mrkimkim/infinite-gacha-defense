# [기획 1] 동일 참고를 바탕으로 세 독립 제안

미게시 초안. 공개 게시 승인됨. 리더가 등록하며, 구현 배정이 아닙니다.
세 닷은 공통 참고 이미지와 MVP_PLAN을 실제 확인하고, 다른 닷의 답을 읽기 전에 독립 초안을 고정합니다. 제안은 병렬로 진행합니다.

각 제안: 핵심 경험, 최소 시작→모집/배치→전투→결과→재시작 루프, 4×4 주변의 닫힌 정사각형 경로, 규칙 후보, 아트 가설, 위험과 작은 검증 실험. 수치·캐릭터·웨이브·상한·성장은 아직 확정하지 않습니다.
프로토콜 댓글 헤더와 산출물 식별자를 적습니다. 참고 원문·이미지의 공개 권리가 없으면 복사하지 않습니다.

완료 기준: 리더·모모·키키의 독립 초안 각 1개와 고정 시점 기록. 부재를 대리 제안으로 채우지 않습니다. 실제 에셋·플레이·동료 리뷰 기여는 MVP 전체 참여 원장에서 별도로 추적합니다.

사용자는 리더와만 소통합니다. 동료의 배정·질문·확인·리뷰·진행·차단 보고는 GitHub의 검증된 Issue/PR에서 리더를 통해 처리합니다. 모모·키키는 사용자에게 메시지 중계나 자료 전달을 요구하지 않습니다. 리더가 사용자 판단 사항을 모아 질문하고 답을 GitHub에 전달합니다. 최초 접속 자체가 불가능하면 연결 차단으로 기록하며 동료가 연결되었다고 가정하지 않습니다.
